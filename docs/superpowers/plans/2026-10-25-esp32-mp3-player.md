# ESP32 WROVER-E MP3 Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MP3s from SD → decoded on ESP32-WROVER-E → A2DP (SBC) to AirPods, controlled from an iPhone browser over the ESP32's own SoftAP.

**Architecture:** Decoder worker task (core 1) reads SD + decodes MP3 into a PSRAM SPSC ring buffer; the A2DP callback only drains the ring. A controller task owns all state changes via a command queue; async web handlers only enqueue commands and read a state snapshot.

**Tech Stack:** PlatformIO, Arduino framework (ESP32), `ESP32-A2DP` (pschatzmann), `arduino-audio-tools`, `libhelix`, `ESP32Async/ESPAsyncWebServer`, `AsyncTCP`, Unity (host tests, `native` env).

**Spec:** `docs/superpowers/specs/2026-10-25-esp32-mp3-player-design.md` (rev 3). Executors read both.

## Global Constraints
- Board `esp-wrover-kit` (verify vs actual dev board), `framework = arduino`, `board_build.partitions = huge_app.csv`, `-DBOARD_HAS_PSRAM`.
- Codec: Bluetooth Classic A2DP with SBC. Audio: 44.1 kHz stereo MP3 → signed 16-bit stereo PCM; other formats rejected with a clear message.
- SD SPI (VSPI): SCK=18, MISO=19, MOSI=23, CS=25 in `config.h`. Never use GPIO 16/17 or strapping pins 0, 2, 5, 12, 15.
- SoftAP SSID `esp32-mp3`, WPA2 password in `config.h`, address `192.168.4.1`. The hotspot is a product requirement; dropping it needs the user's decision.
- `AIRPODS_NAME` for initial discovery only; then NVS-stored peer address, reconnect backoff 1 s → 30 s, states `disconnected`/`connecting`/`connected`.
- All dependency versions pinned after Task 1; no floating versions.
- No claim of smooth playback until Task 7 passes.

## Review Focus
1. Empty SD / SD missing / zero `.mp3` files: no crash; state shows error (Task 2, 4).
2. Every track unsupported (e.g. 48 kHz or mono): stops with `no playable tracks`, never loops (Task 2, 4).
3. Rapid NEXT/PREV spam or TRACK during a track change: commands queue, no race or crash (Task 4).
4. macOS `._*` files and non-ASCII/mixed-case filenames on the card: ignored / sorted deterministically (Task 2).
5. `limit`/`offset` out of range or garbage in `/api/tracks` and `v` in `/api/volume`: clamped, never crashes (Task 6).

## File Structure
- `platformio.ini` — envs `esp32` (firmware) and `native` (host tests, `test_build_src` off; pure-logic headers only).
- `include/config.h` — pins, SSID/password, `AIRPODS_NAME`, buffer sizes.
- `lib/core/RingBuffer.h` — SPSC byte ring (pure C++, host-testable).
- `lib/core/TrackList.h` — filter, sort, page, navigation (pure C++).
- `lib/core/Commands.h` — command enum + state structs (pure).
- `src/DecoderWorker.{h,cpp}` — SD + Helix decode → ring.
- `src/BtAudio.{h,cpp}` — A2DP source, callback, connection manager.
- `src/Controller.{h,cpp}` — command queue, track-change sequence, state snapshot.
- `src/WebApi.{h,cpp}`, `src/index_html.h` — SoftAP, routes, embedded page.
- `src/main.cpp` — boot checks, wiring.
- `test/test_core/*.cpp` — Unity host tests.

**Interfaces — Produces:**
```cpp
class RingBuffer { public:
  RingBuffer(uint8_t* mem, size_t capacityBytes);        // capacity % 4 == 0
  size_t write(const uint8_t* d, size_t n);              // producer only; returns bytes accepted
  size_t read(uint8_t* out, size_t n);                   // consumer only; whole 4-byte frames
  size_t available() const;  size_t freeSpace() const;
  void flush();                                          // only while producer stopped
};
size_t fillPcm(RingBuffer&, uint8_t* out, size_t n);     // copies whole frames, zero-fills rest, returns frames copied*4
std::vector<std::string> buildTrackList(const std::vector<std::string>& dirNames); // *.mp3 ci, drop dot files, sort ci then bytewise
struct Page { size_t total, offset; std::vector<std::pair<size_t,std::string>> items; };
Page pageTracks(const std::vector<std::string>&, long offset, long limit);          // limit clamp 1..50, offset>=total → empty
int nextIndex(int cur, size_t total);  int prevIndex(int cur, size_t total);        // -1 = stop/stay per spec
```

### Task 3: Audio path to AirPods (hardware gate 0, Wi-Fi off)

**Files:** Create `src/DecoderWorker.{h,cpp}`, `src/BtAudio.{h,cpp}`; Modify `src/main.cpp`.

**Interfaces:** Consumes `RingBuffer`, `fillPcm`. Produces:
```cpp
class DecoderWorker { public:
  void begin(RingBuffer&, uint8_t core = 1);
  void open(int index);                 // enqueue; worker opens file, resets decoder
  void requestStop();                   // worker closes file, then notifies ack
  bool waitStopped(uint32_t ms);        // controller blocks for the ack
  enum Result { PLAYING, ENDED, UNSUPPORTED, IO_ERROR } status() const;
  String lastError() const;
};
class BtAudio { public:
  void begin(RingBuffer&);              // registers data callback = fillPcm
  void setVolume(uint8_t v0to100);
  enum State { DISCONNECTED, CONNECTING, CONNECTED } state() const;
  uint32_t underruns() const;           // counted only if expectAudio==true
  void expectAudio(bool);
};
```
- [ ] **Step 1:** Implement worker: open `/NN.mp3` by sorted index, Helix decode, reject non-44.1 kHz/stereo with `UNSUPPORTED` + message, push PCM to ring when space (sleep otherwise).
- [ ] **Step 2:** Implement `BtAudio` with `AIRPODS_NAME`; callback only calls `fillPcm` and counts underruns when `expectAudio` is true.
- [ ] **Step 3:** Temporary `main.cpp`: play track 0, loop through list, print underruns/heap every 10 s.
- [ ] **Step 4:** `pio run -e esp32` → SUCCESS. Flash, pair AirPods using the procedure for the actual model. Expected: audible MP3, `underruns` stays 0 over 10 min smoke test.
- [ ] **Step 5:** Run the 30 min acceptance run 1 (Wi-Fi off); record results in `docs/acceptance.md`. Commit.

### Task 4: Controller, command queue, track-change sequence

**Files:** Create `src/Controller.{h,cpp}`; Modify `main.cpp`; Test `test/test_core/test_controller_logic.cpp` for the pure state machine (`lib/core/Commands.h`).

**Interfaces — Produces:**
```cpp
enum class Cmd { Play, Pause, Next, Prev, Volume, Track };
struct Command { Cmd cmd; int arg; };
enum class PlayState { Stopped, Playing, Paused };
struct StateSnapshot { PlayState play; int track; uint8_t volume; BtState bt; String error; uint32_t underruns; uint32_t minFreeHeap; };
class Controller { public:
  void begin(DecoderWorker&, BtAudio&, const std::vector<String>& tracks);
  bool enqueue(Command);                 // non-blocking, from any task; false if queue full
  StateSnapshot snapshot() const;        // copy, lock-free read
};
// pure, host-testable
int skipPolicy(int start, size_t total, std::function<bool(int)> playable); // first playable ≥ start, bounded by total attempts; -1 if none
```
